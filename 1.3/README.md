Version 1.3

This version changes the left joystick to arrow keys and scrolling.

- Right joystick = Mouse
- Left joystick left/right = Left/right arrow keys
- Left joystick up/down = Scroll up/down, push further to scroll faster
- R2 = Left click, hold to drag
- L2 = Right click
- D-pad = Arrow keys
- Cross = Space
- Circle = Escape
- Square = Enter
- Triangle = Backspace
- Touchpad click = Open or close the Windows keyboard
